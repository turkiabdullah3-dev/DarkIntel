# v1.0.0 release checklist

- [ ] Python compilation and full tests pass on Python 3.11.
- [ ] Frontend `npm ci`, typecheck, tests, and production build pass.
- [ ] Bandit, pip-audit, and npm production audit findings are reviewed.
- [ ] Atomic-write, locking, backup, tamper, and production SPA tests pass.
- [ ] Synthetic demo is generated and reviewed in every dashboard page.
- [ ] Docker image builds, runs as non-root, and becomes healthy on loopback.
- [ ] No secrets, real cases, caches, build output, or developer paths are tracked.
- [ ] README, SECURITY, CONTRIBUTING, and CHANGELOG are current.
- [ ] Upstream license status and redistribution obligations are resolved by the maintainer.
- [ ] Confirm an authoritative root `LICENSE` or `COPYING` file before any public release.
- [ ] Aryan Guenthner and DarkFox attribution is preserved.
- [ ] Repository naming and branding are approved.
- [ ] Git status contains only intentional release changes and the diff is reviewed.
- [ ] Central version is updated and changelog release date is prepared.
- [ ] Maintainer explicitly approves commit, push, tag, image publication, and GitHub release.
