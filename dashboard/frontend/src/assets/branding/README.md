# Branding assets

`source-logo.jpg` is the authoritative supplied artwork and is retained for future derivation. The active assets are faithful transparent-background raster crops: `logo.webp` is the complete symbol, `logo-mark.webp` is the square compact navigation mark, and `favicon.png` is optimized for browser icon sizes and portable `image/png` serving. They contain no added text, effects, remote references, or redrawn geometry. Asset paths remain centralized in `src/config/branding.ts`.
